This quickstart walks you through the most common tasks — fetching historical candles, reading a live quote, and watching a live price stream — using the high-level Data API. All examples use Binance BTC/USDT and work **completely anonymously**: no TradingView account is required.

<Steps>

<Step title="Install">

Install the package with your preferred package manager. Node.js ≥ 20 or Bun is required.

<CodeGroup>

```bash npm
npm install @mathieuc/tradingview
```

```bash yarn
yarn add @mathieuc/tradingview
```

```bash pnpm
pnpm add @mathieuc/tradingview
```

```bash bun
bun add @mathieuc/tradingview
```

</CodeGroup>

</Step>

<Step title="Fetch candles">

`getCandles` is a one-shot function: it opens a connection, waits for TradingView to return the complete bar history, then closes everything and resolves with the result. No teardown code needed.

```typescript
import { getCandles } from '@mathieuc/tradingview/data';

const candles = await getCandles({
  symbol: 'BINANCE:BTCUSDT',
  timeframe: 'D',   // Daily bars. Use '60' for 1 h, '15' for 15 min, etc.
  count: 40,        // Most recent 40 bars, oldest first.
});

console.log(candles.at(-1));
// { time: 1748908800, open: 103241, high: 105819, low: 102889, close: 104976, volume: 18423.7 }
```

A few things to know about the result:

- **`time`** is the bar **open** time in Unix **seconds** (not milliseconds).
- The array is **oldest-first**: index `0` is the oldest bar, `at(-1)` is the latest.
- Omit `count` to get the default 100 daily bars, or pass `from: new Date(...)` to load a date range.
- Anonymous access is limited to roughly **7 000 one-minute bars**. Daily and weekly history is much longer without an account.

</Step>

<Step title="Get a live quote">

`getQuote` returns the latest snapshot for a symbol in a single async call.

```typescript
import { getQuote } from '@mathieuc/tradingview/data';

const quote = await getQuote('BINANCE:BTCUSDT');

console.log(quote.lp);    // Last price
console.log(quote.chp);   // Change percent (e.g. 1.45)
console.log(quote.ch);    // Change in currency units
console.log(quote.bid);   // Best bid
console.log(quote.ask);   // Best ask
console.log(quote.volume); // 24 h volume
```

A quote object contains all the fields TradingView sent: `lp`, `lp_time`, `ch`, `chp`, `bid`, `ask`, `volume`, `open_price`, `high_price`, `low_price`, `prev_close_price`, `description`, `currency_code`, and more.

</Step>

<Step title="Watch live candles">

`watchCandles` resolves once the initial history is loaded, then keeps calling `onData` on every new tick or candle close. Call `watcher.stop()` to unsubscribe and clean up.

```typescript
import { watchCandles } from '@mathieuc/tradingview/data';

const watcher = await watchCandles(
  {
    symbol: 'BINANCE:BTCUSDT',
    timeframe: '1',   // 1-minute bars
    count: 50,        // Keep the last 50 bars in each snapshot
  },
  {
    onData(candles) {
      const latest = candles.at(-1);
      console.log(`[${new Date(latest!.time * 1000).toISOString()}] close: ${latest!.close}`);
    },
    onError(error) {
      console.error('Stream error:', error.code, error.message);
    },
  },
);

// The promise above resolves once the initial snapshot has arrived.
// Keep watching for 30 seconds, then stop.
await new Promise((resolve) => setTimeout(resolve, 30_000));
await watcher.stop(); // Idempotent — safe to call more than once
```

Key details:

- Each `onData` call receives a **frozen array** of the `count` most recent bars, oldest first.
- `watcher.latest` always holds the most recent snapshot.
- `watcher.closed` is a `Promise` that resolves when the watcher stops (after `stop()`, a cancelled `signal`, or a fatal error).
- There is **no automatic reconnection**. Start a new watcher if `closed` resolves due to a disconnection.

</Step>

</Steps>

<Tip>
  Store your TradingView credentials in a `.env` file (use `.env.sample` in the repo as a template) and load them with Node's built-in `--env-file` flag:

  ```bash
  node --env-file=.env my-script.mjs
  ```

  Then read them in code with `process.env.TV_SESSION` and `process.env.TV_SIGNATURE`. Never commit credential values to source control.
</Tip>
