TradingView-API (`@mathieuc/tradingview`) is a community-built TypeScript/JavaScript library that gives you programmatic access to TradingView market data: OHLCV candles, real-time quotes, Pine indicator values, strategy reports, and symbol screeners. It works in Node.js ≥ 20 and Bun, over WebSocket and HTTP — no official TradingView API key required.

## Get started in one line

```bash
npm install @mathieuc/tradingview
```

```typescript
import { getCandles } from '@mathieuc/tradingview/data';

const candles = await getCandles({ symbol: 'BINANCE:BTCUSDT', timeframe: 'D', count: 40 });
console.log(candles.at(-1)); // { time, open, high, low, close, volume }
```

<Note>
  TradingView-API is an **independent community project** — it is not affiliated with or endorsed by TradingView. Always check your data provider's terms and applicable market-data permissions for your use case.
</Note>

## Two ways to use the library

<Tabs>
  <Tab title="Data API (recommended)">
    Import from `@mathieuc/tradingview/data` for a simple, managed interface. Every function opens its own connection, collects the data, and cleans up — including on errors, timeouts, and cancellation.

    ```typescript
    import { getCandles, getQuote, getIndicatorData } from '@mathieuc/tradingview/data';

    const candles = await getCandles({ symbol: 'NASDAQ:AAPL', timeframe: '60', count: 200 });
    const quote   = await getQuote('NASDAQ:AAPL');
    const rsi     = await getIndicatorData({ symbol: 'NASDAQ:AAPL', indicator: 'STD;RSI' });
    ```
  </Tab>
  <Tab title="Low-Level API">
    Import from `@mathieuc/tradingview` for full control. Manage one persistent connection with multiple chart and quote sessions, replay mode, and raw packet access.

    ```typescript
    import { TradingViewClient, getIndicator } from '@mathieuc/tradingview';

    const client = new TradingViewClient();
    const chart  = client.createChart();

    chart.on('update', () => console.log(chart.lastCandle?.close));
    chart.setMarket('BINANCE:BTCUSDT', { timeframe: '60', count: 300 });

    await client.close();
    ```
  </Tab>
</Tabs>

## Interactive quick-start

Run the interactive launcher from your project directory to get a working example without writing any code:

```bash
npx @mathieuc/tradingview
```

The launcher can open a hosted market-watcher, start a local coding agent (Claude Code or Codex), print a ready-to-use prompt, or install the library — your choice.
